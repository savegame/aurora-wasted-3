# RE3 для ОС Аврора

Порт **RE3** (reverse-engineered GTA III) для мобильной операционной системы [Аврора](https://auroraos.ru/).

RE3 — это полностью переписанный движок GTA III с открытым исходным кодом, основанный на реверс-инжиниринге оригинальной игры. Данный порт адаптирует проект для работы на устройствах под управлением ОС Аврора с сенсорным управлением.

> ⚠️ **Важно:** Для запуска игры требуются легально приобретенные оригинальные файлы игры GTA III (не входят в поставку).

---

## Особенности порта

### Адаптация GLFW3 для Wayland
- Поддержка `wl_shell` и `qt_extended_surface` для совместимости с Aurora OS
- Корректная обработка событий окна и visibility callbacks
- Интеграция с системой ввода Wayland

### Dual-FBO рендеринг
- Разделение рендера на два буфера: 3D-сцена и UI
- 3D-контент рендерится в уменьшенном разрешении для производительности
- UI (HUD, меню, сенсорные элементы) рендерится в нативном разрешении
- Настраиваемый масштаб 3D-буфера

### Сенсорное управление
- Виртуальный аналоговый стик для перемещения
- Экранные кнопки с поддержкой нескольких раскладок:
  - **Gameplay** — полный набор для игры
  - **Menu** — навигация по меню
  - **Cutscene** — управление во время роликов
- Зона камеры для управления обзором
- Динамическая видимость кнопок в зависимости от контекста (пешком/в транспорте)

### Поворот экрана
- Рендеринг в ландшафтной ориентации на портретном дисплее
- Автоматическая трансформация координат ввода
- Поддержка поворота на 90°/180°/270°

### Управление энергосбережением
- Интеграция с Aurora MCE (Mode Control Entity)
- Запрет гашения экрана во время игры
- Автоматическое восстановление при сворачивании

### Лаунчер
- Графический интерфейс для запуска игры
- Выбор пути к игровым ресурсам
- Проверка наличия необходимых файлов
- *🔜 В будущем: настройки графики и управления*

### SearchPaths
- Гибкая система поиска ресурсов
- Поддержка ресурсов, встроенных в пакет приложения
- Поддержка пользовательских путей к ресурсам
- Приоритетный порядок поиска

## Установка

> ⚠️ **Примечание:** Перед игрой на ОС Аврора необходимо легально приобрести копию GTA III для ПК (например, в [Steam](https://store.steampowered.com/app/12100/Grand_Theft_Auto_III/) (ссылка протухла 😁) или [Rockstar Games Launcher](https://www.rockstargames.com/games/grandtheftauto3)).

1. В настройках разрешите установку пакетов без подписи источника
2. Установите RPM-пакет на устройство с ОС Аврора
3. При первом запуске укажите путь к файлам GTA III
4. Наслаждайтесь игрой!

---

## Сборка

```bash
# Клонирование репозитория вместе с сабмодулями
git clone --recursive git@github.com:savegame/aurora-wasted-3.git
cd aurora-wasted-3

# Сборка под Aurora OS (требуется Aurora SDK)
mb2 build-init
mb2 prepare
mb2 build
```
